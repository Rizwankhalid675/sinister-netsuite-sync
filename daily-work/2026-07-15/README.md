This is a git repository, but commits are **task-based, not daily** — work is committed
when a chunk is finished, not on a fixed calendar day. So there is no reliable per-day
diff. To see the real history:

    cd website-revamp/sinister-revamp
    git log --oneline --stat -- .

Commit dates in that log show when each finished piece of work landed.
